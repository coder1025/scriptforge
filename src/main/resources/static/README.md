# 前端开发说明

不依赖构建工具或 CDN。`index.html`、`style.css`、`app.js` 与 `demo.json` 使用相对路径，既能由 Spring Boot 提供，也能复制到 GitHub Pages 项目子目录。

- 正常打开：先请求同源 `/api/config`，连接后端任务、模板和执行记录。
- `?demo=1`：只读固定样例回放，不调用模型或创建后端任务。
- 后端不可达：明确提示后回退到离线样例。已连通后出现的权限错误不会静默回退。
- 管理令牌：仅存放在当前标签页的 `sessionStorage`，通过 `Authorization: Bearer` 发送。页面不接受或保存模型 API Key。
- 使用 `textContent` 和 DOM 节点插入所有任务、模型和用户内容，不将这些内容作为 HTML 渲染。
- 后端任务轮询约 1.3 秒一次；终态、隐藏标签页停止轮询。
- 任务输入为冻结快照：前端支持创建前编辑；没有伪造运行中修改接口。
- 只有 `PAUSED` 任务提供恢复按钮；取消保留已存稿件供查看和导出。
- 旧版报告明确标记为不可用于当前稿，版本比较显示段落级增删，不冒充字符级 diff。

`demo.json` 的文本、报告、耗时、Token 数和上下文均是手工设计的虚构样例，不是模型评测结果。默认展示结束状态；点击播放会从头回放。真实 DEMO 后端仍运行宿主与工具，只替换模型；MODEL 模式才调用真实模型。

建议浏览器验收：桌面 1440×1000 / 390×844；切换正文、计划、版本对比、任务资料、审稿、上下文；播放到 v3 错误 → v4 修复；检查只读模式禁写；连接真实后端创建默认任务并等待 `DEMO_READY`；导出 Markdown；输入含 `<script>` 的任务文本确认以纯文本显示。
